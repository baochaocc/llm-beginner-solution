# 实际运行截图：终端命令清单

> 用途：在 VS Code 自带终端（PowerShell）里逐条执行，按下文顺序截图，
> 即可作为实验报告的"实际运行截图"。全部命令都在**仓库根目录**执行。

## 0. 准备（每个新终端窗口执行一次）

```powershell
cd D:\llm-beginner-master
chcp 65001 > $null                      # 终端切 UTF-8，避免中文乱码
$env:PYTHONIOENCODING = "utf-8"         # Python 输出按 UTF-8
$env:TRANSFORMERS_VERBOSITY = "error"   # 少打日志
```

## 2. 截图②~⑦：任务一~六的官方自检

每个任务跑完截一张（`cls` 先清屏，画面更干净）：

```powershell
cls; python task-1-transformer/eval/run.py      # 任务一（约 5 秒）
```

## 5. 截图存放建议

把截图放到 `docs/screenshots/` 下并按同样命名（`env.png`、`task-1.png` …），
这样 `实验报告.md` 里已有的图片引用无需修改；若用其它文件名，同步改一下报告里的
图片路径后重新生成 Word：

```powershell
python scripts/md_to_docx.py "实验报告.md" "实验报告.docx"
```
